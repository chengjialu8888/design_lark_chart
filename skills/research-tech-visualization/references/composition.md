# 构图、主题与综合页面

具体构图、字体与素材制作见 [page-recipes.md](page-recipes.md)，可用主题见 [themes.md](themes.md)，可编辑起点见 [assets.md](assets.md)。

## 先匹配语境

检测当前项目的颜色变量、字体、组件、间距和交互风格。明确的用户新方向覆盖旧默认，否则延续已有语言；不要为一个新图引入整套新设计系统。

新建时先定主问题、阅读顺序与一个主视觉焦点，再安排容器。页面不是图的集合：每一节要帮助解释、比较、验证或限定一个问题。

## 不固定审美答案

浅色文档便于正文阅读与打印，编辑式版面利于讲述，深色技术演示可用于特定展示；根据上下文选择，不因“科技”自动用霓虹和等宽字。配色、字体、卡片、圆角、阴影都是可替换策略，不是质量底线。

区分类别身份、状态与编辑强调。同方法在不同图中的颜色和名称稳定；重点用尺寸、位置、标签或线宽补充，不能既表示“方法A”又表示“最好”。颜色不是唯一信息编码。

中文正文使用实际可用且覆盖字符的字体，保留完整术语与标点。代码、端口等可以等宽，所有名字不必等宽。检查孤字、错误拆词、标题过长和中英混排，而非只看是否溢出。

短标题可通过平衡换行、调整栏宽或按完整词组断行改善孤字，优先于缩字。横向滚动图/表不仅提供可访问名称，还要给窄屏读者可见的滑动提示。

## 学术与技术页面

按材料组织研究问题、方法、机制、实验、限制、引用等所需章节，不机械补足所有章节。首屏用真实核心图或结论建立焦点，不必额外生图。标题说明研究对象及意义，避免未经证实的宣传词。

复杂架构近旁给总体说明，细节按稳定标识展开。实验图附近写清数据集、配置、单位与不确定性，完整结果保留可查表格；引用与局限不只藏在 hover 中。

用对齐、层级和留白组织页面；卡片只有在分组/交互有用时采用。图注、标题和正文分工，不重复相同结论。用户只改局部时保持其他结构。

## 阅读尺寸与无障碍

- 图的有效字号约为源字号乘显示宽/画布宽；高倍 PNG 不解决缩小后的字号。窄屏重排、局部展开或明确图内滚动，不让整页意外横向溢出。
- 用语义 HTML、可见键盘焦点、真实按钮与链接。交互图有静态替代或数值表；触摸和键盘不依赖 hover。
- SVG 使用 `role="img"` 和可解析的 `aria-labelledby` 指向本图 `<title>` 与 `<desc>`；装饰图用 `aria-hidden="true"`。多个内联图的 ID 加前缀避免重复。
- 文字对比按 WCAG AA 目标检查。跨背景、透明叠加和图像内文字需要实际看图，简单色值计算不能覆盖。
- 动画仅在有说明职责时添加；尊重 `prefers-reduced-motion`，打印和无脚本状态仍保留内容。

## 实际复核

在目标桌面宽度和窄屏宽度分别看首屏、密集区域与全页节奏。图表可读、图注可定位、跨图身份一致比统一等高更重要。

如果用户只需要论文插图，不额外制作整个网页。若页面依赖外部图表库/字体，明确依赖；离线需求要单独验证，单 HTML 文件不是证据。
