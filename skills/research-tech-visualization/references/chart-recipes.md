# 实验图配方：从问题到图型

在 [实验与指标](experiments.md) 完成口径核对后读取。图型、字段需求、标注与多面板联动设计；图型选择范围不等于随包渲染脚本的支持范围。

## 配方矩阵

| 问题 | 最小数据 | 首选表达 | 容易误导的地方 |
| --- | --- | --- | --- |
| 多方法单指标差多少 | 方法、同口径指标、值 | 横向点图/条形图 | 长标签截断、条形非零基线 |
| 各数据集是否一致 | 方法 × 数据集 × 同定义指标 | 小多图＋全量表 | 每面板偷偷换范围、跨任务盲平均 |
| 加模块带来什么变化 | 基线、变体、控制条件、结果 | 消融表/配对点/差值图 | 无控制条件宣称因果 |
| 训练何时收敛 | step/epoch/time、每次运行的观测 | 折线＋真实区间 | 平滑隐藏峰值、不同 x 轴混同 |
| 结果稳不稳定 | 原始运行值或可信分位数 | 原始点、箱线、小提琴 | 只有均值却生成分布 |
| 质量与成本怎么权衡 | 同条件质量、成本、身份 | 散点/Pareto（适用时） | 坐标挪动避碰撞、声称全局最优 |
| 多参数怎样影响结果 | 参数网格、指标、未测状态 | 热力图＋数值 | 未测填零、色阶按每行重标而未声明 |
| 时间花在哪里 | 阶段耗时与是否重叠 | 堆叠条/时间线/trace | 重叠阶段直接相加 |
| 总量为何变化 | 起始、可加的增减项、终值 | 瀑布图 | 不能守恒却假定归因完整 |
| 数据怎样分配 | 同单位守恒流量 | 桑基图 | 普通依赖箭头无流量也画宽度 |

单一图型不是所有问题的答案：准确率、毫秒、GB 优先各一面板；不是把不同单位放在一组柱里。雷达、双轴、气泡、面积与 3D 可按需求采用，但须解释尺度和读数代价。

## 一、多实验板的组织顺序

先定义比较键（如 dataset/split/config/metric）和稳定方法身份，再选小多图的分面维度。同指标同定义的面板通常共享值轴；不同定义/不同尺度必须明确独立轴。不为“统一画面”强行用一个范围把变化压扁。

保留全量结果表，图突出读者要比较的维度；若只展示子集，写筛选条件、省略数量与完整入口。方法排序选固定身份顺序、基线优先或某个明确指标；排序改变不能让颜色跟着数组索引跑。

每面板附近交代数据集、单位、方向、硬件/配置、摘要类型和误差含义。很长条件可共用一处清晰图注，不把关键差异藏在 hover。失败运行数与成功观测数分开。

## 二、均值、区间与分布

- 点图的点表达给出的估计值；横向区间表达同条记录提供的 low/high。不默认它是 95% CI，也不把 SD 写成 CI。
- 只有均值：画点并标“区间未提供”；`n` 未知保持未知。不画零长度误差线暗示绝对稳定。
- 原始独立重复：保留每次记录，再按所需统计聚合；SD、SE、CI 的公式与独立单位写清。一次运行的批次不是自动等价的独立重复。
- 箱线图需声明 Q1/中位数/Q3、须线规则和离群点处理；须线不一定是最小/最大。小提琴的带宽、样本量和边界可能制造平滑假象，小样本优先原始点。
- 区间是否重叠不等于显著性检验；误差条视觉距离不作统计结论。

## 三、收敛与趋势

x 轴是实际 step、epoch 或 wall time；不同预算和采样密度要可辨。平滑保留原始数据、窗口与方法；可同时显示弱化原始线和明确的平滑线，不能用平滑制造已达标。

缺失不跨段直接连线，除非明确插值；提前停止与未完成分别标记。线尾标签可减少往返图例，但拥挤时使用分面/选择重点，不能删除不利的方法。

## 四、成本—质量与矩阵

散点中心由共享比例尺直接计算，不为避重叠挪点。标注可移动并用引线关联；气泡第三维按面积而非半径编码，负值不适合作面积。Pareto 仅相对于已观测的同口径点，方向明确且不自动连成因果曲线。

热力图连续数值使用顺序色；围绕有意义中心的偏差才使用发散色，中心写明。空值独立纹理/NA，不借用最浅色当零。不同指标的混合矩阵必须逐列声明单位与标准化方法；不要从浅深直接比较毫秒与百分比。

## 五、标题、标注与精确值

信息分工：标题回答问题或陈述有依据的事实；副标题补口径；值标签给必要读数；标注补充比较、阈值、事件或区间；来源落在可见图注。不在四个地方重复同一结论，也不机械加“洞察”框。

标注用完整业务键命中唯一对象，不以当前数组位置猜对象。差值应能由原值复算：百分点与相对变化分开；零/负基数先处理定义。增加不等于有利，下降不等于风险，方向未知用中性色。

绘图用完整精度，显示按任务舍入，并说明精度；不能先粗舍入再比较“最佳”。对图形按 `pixel = start + (value - min)/(max - min) × extent` 复算，确认标签、数据和坐标来自同一版本。面积、角度和堆叠累计边界另按相应定义检查。

## 实现选择

数据先用专用解析器读取 CSV/TSV/XLSX/工具返回；PDF/截图提取的关键值逐一核对。不要让用户为满足脚本自行重抄表格。

现有项目使用 ECharts/VChart/Matplotlib/Plotly 时沿用；它们字段不通用，不能把一种配置改个名字就传给另一种。随包 `render_chart_assets.py` 只提供**均值摘要的五种起手图**，不聚合 raw、不算显著性、不支持全部表中图型。遇到支持范围外的数据换合适工具，不静默丢记录。
