# 制作、检查与交付

## 选择与保留源

独立精确图保留原生 SVG；数据图保留原始/规范化数据与绘图配置或脚本；页面保留完整 HTML/CSS/必要 JS 或已有项目组件。按请求输出 PNG/PDF 等，不自动生成全部格式。

文字可改、节点关系可改、数据可改、指定软件可编辑是不同承诺。位图封装不算节点可编辑，普通 SVG 不保证每个编辑器无损支持，PDF 需区分矢量与位图。源、预览和数据同版本，修改后只更新受影响结果及必要联动。

## 五层检查

| 层 | 必须核对 | 有限的自动支持 |
| --- | --- | --- |
| 来源事实 | 名称、职责、关键关系与结论有准确定位 | 无自动事实证明 |
| 数据统计 | 单位、可比组、缺失、重复、派生计算和结论 | `check_experiments.py` 检查显式数据契约，不计算显著性 |
| 结构语义 | 文档、ID、引用、节点/边完整性及真实语义 | `check_artifact.py`；语义仍需人工核对 |
| 渲染视觉 | 实际资源、字体、文字、裁切、连线、可读性 | `check_render.mjs` 有限浏览器检查与截图；之后实际看图 |
| 交付编辑 | 文件可访问、格式与尺寸真实、源与预览一致 | 读回文件/尺寸，必要时实际导入；不能只依赖扩展名 |

每层使用“通过 / 发现问题 / 未执行 / 不适用 / 待复核”，附实际证据。自动报告的 `checks_passed` 只表示所列检查通过，不表示整件作品合格。

飞书交付另按 [飞书分享](feishu-sharing.md) 及所选路线检查：本地转换、服务端保存、宿主实际渲染、访问范围是独立证据。HTMLBox/原生图表需检查远端块与真实客户端；妙搭需确认本轮 release 完成及实际分享范围。未执行远端操作时只报告本地准备通过。

## 静态结构检查

```bash
python3 "$SKILL_DIR/scripts/check_artifact.py" "$HTML_OR_SVG"
```

Python 3.10+ 标准库，无网络、无执行页面脚本、无写入。支持完整、显式闭合的 HTML 文档和 XML SVG。HTML 的可省略闭合标签、复杂嵌入命名空间等超出子集时修复新生成的简单文档，或换适合的验证工具；不要为了检查旧组件而扩大局改范围。

检查文档结构、重复 ID、本地片段/ARIA/marker 引用、SVG viewBox 与图形描述、标记节点/边引用。列出可识别的外部资源和动态代码；不是安全审计、通用 HTML 验证或离线证明。CSS 动态 URL、网络 API、构建时依赖和运行结果不能靠静态扫描完整判断。

## 浏览器检查与预览

需要已安装的 Node.js 18+、Playwright 包和可用 Chromium；依赖缺失返回 `not_run`，不自动安装。不依赖 Python Playwright。

```bash
node "$SKILL_DIR/scripts/check_render.mjs" "$HTML_OR_SVG" --out "$PNG_PATH" --width 1440 --height 1000
```

可用 `--browser "$CHROMIUM_PATH"` 指定已装浏览器。包不在默认搜索路径时通过当前环境的 `NODE_PATH` 指定已安装包目录；不要写死本机路径进产物。

- 仅检查本次生成或已经审查的可信本地文件。默认禁用 JavaScript；确需运行生成的图表脚本时加 `--allow-scripts`，不要用于来源不明的 HTML。
- 阻断网络及源目录以外的文件请求，收集失败资源；不因此宣称通过安全隔离或离线验证。网络必需的作品要在获准的实际环境中另行检查，不禁用安全限制绕过。
- 默认拒绝覆盖预览，明确重生成时可加 `--force`。报告和截图关联输入 SHA-256；修改源后旧截图不再是当前验证证据。
- 独立 SVG 用临时 HTML 外壳按指定视口宽度预览，保留原图和相对资源基址；报告 `svg_preview_wrapper`，结束后删除自己创建的临时外壳。它是阅读预览，不是精确原画布尺寸的导出器。
- 检查页面横向溢出、字体就绪、已渲染 SVG 文字边界，以及 [结构标记](structure.md#可选的浏览器检查标记) 的有限矩形/折线路径几何。曲线、旋转、非矩形与缺少元数据报告覆盖不足。
- 统计图 SVG 可标 `data-viz-type="chart"`，表示不适用节点/边几何，但仍检查 SVG 文字。它不是跳过技术图检查的开关；数据位置、轴与比例仍须按实验规范核对。
- 小字号提示是复核线索，不是统一字号法律；文字重叠检测可能把有意叠层作为候选，结合真实图面判断。图例、主次、真假关系、CJK 字形缺失和图像内文字仍要实际查看。
- 窄屏用相同命令改 `--width 390`，写不同预览路径；这不是所有设备测试。页面区域滚动可合法，但整图缩小到无法阅读不合格。

浏览器检查退出码：0=所列检查无错误，1=发现问题，2=无法运行/参数或环境问题。warnings/coverage 不能忽略。

## 导出与结束

有适合的宿主预览/浏览器工具时可用，不强制为了检查安装新工具。实际看最终图；浏览器自动探测不是目视通过。

独立图改动只复核该图及相关页面；公共字体、数据、颜色身份变化则检查共享消费者。失败先定位，不重复相同无效命令；关键问题未解决就明确说明。

交付简述：展示范围/来源版本、实际文件、具体可修改范围、完成的检查、未执行项和剩余限制。只交用户需要的成果，临时日志与缓存留工作目录。远端写入额外读回，保存成功不等于已展示、已发布或用户已取得。
