# 主题、语义颜色与字体

主题与图形语法独立。流程、泳道、时序、循环等方法可配任一合适主题，不绑定默认配色。用户指定、已有项目风格与方法身份优先；本库不是选择上限。

## 可直接使用的主题

`assets/themes.json` 是颜色真源，`themes.css` 是页面消费文件，`theme-gallery.html` 是实际预览。修改 JSON 后用 `scripts/build_theme_assets.py` 重建，避免两处手工改色。

**默认主题为 `bytedance`（字节蓝青）**。选择顺序为：用户明确指定 → 既有项目视觉约束 → 字节蓝青。默认仅作用于新内容，不追溯修改已交付页面或已锁定的方法身份。`themes.json` 的 `default_theme` 驱动 CSS 根变量和未指定 theme 的图表生成；其他配色保留为可选主题，历史 ID `default_blue` 不代表当前默认。

## 字节蓝青 / bytedance

这是一套为本 skill 设计的字节跳动风格主题，**不是官方 VI 复刻**；不默认添加品牌标志或官方背书。可编辑实景见 [bytedance-theme.html](../assets/bytedance-theme.html)。适合把方法说明、架构与多个实验放在同一视觉系统中。

- **颜色职责**：冷白 `#F5F8FF` 承载页面、纯白承载图面；深墨 `#18243B` 用于正文。蓝 `#325AB4` 用于主路径、章节重点和按钮；亮青 `#00B5C9`、浅青 `#78E6DC` 只作少量装饰，不用于正文、唯一的关键边界或定量渐变。关键次级图形用深青 `#087E8B`，文字仍用 ink/link。
- **排版与构图**：系统无衬线字体，正文 16–18px、桌面标题 40–60px、图内文字 14–16px；数字等宽。8px 间距节奏、细分隔线、8–12px 圆角；首屏大标题配一张解释性主图，长文不堆满仪表盘卡片。桌面留白充分，窄屏改为纵向阅读，复杂图局部滚动。
- **架构与流程**：白底节点、蓝色实线主路径；反馈/异步等关系需按真实含义用线型和文字说明，青色不自动代表并行或实时。非关键容器可用淡边框，关键边和端口不可用浅灰替代高对比轮廓。内联 SVG 可消费主题变量；外部 SVG 需单独同步。
- **多实验指标**：六色 series 只是离散候选，方法 ID 对应颜色/符号后跨图锁定。六级蓝色 sequential 按低→高使用，不代表结果越大越好；发散指标另配色。不用蓝青渐变填柱高来暗示额外数值，不凭配色添加“领先”或显著性结论。
- **动效与降级**：默认静态；需要讲解时只对已核实路径做短暂描线或阶段聚焦。禁止装饰粒子覆盖图表与文字，保留暂停、减少动态效果和打印的静态结果。

用法：按下文加载 CSS，并设置 `data-theme="bytedance"`。复用预览页时保留其布局样式，按实际内容替换图与表；CSS 色板本身不强制布局。该主题的 ink/muted/link 在 paper/surface/accent-soft 上均通过 4.5:1 检查；亮青装饰色不在正文许可范围内。

## 三类颜色不可混同

1. **页面角色**：paper/surface/ink/muted/line/accent/link 决定承载与可读性。换页面背景不会自动重映射方法颜色。
2. **离散身份**：固定方法/模块 ID → 色值/形状/线型。排序、筛选、跨数据集后映射不变；颜色候选不足时补符号、线型或分面，不循环色板造成歧义。
3. **连续数值**：sequential 表示低→高；围绕有意义中心的正负偏差另设计发散色。离散系列不因为画成堆叠就有大小顺序。图例给范围、单位和缺失状态。

重点、对照、上下文和告警是另外的表达职责，不替换原方法身份。用轮廓、粗细、标注补充重点；告警必须有指标方向/阈值依据，红色不自动表示下降不好。

## 如何实际换肤

HTML 先加载 tokens.css，再加载 themes.css；未指定主题时根变量采用字节蓝青，也可明确写 `data-theme="bytedance"`。指定其他 `data-theme` 可覆盖默认。示例页面保留不同主题以展示选型；用于新任务时按上述优先级决定主题，不把示例的显式选择当成 skill 默认。结构骨架与叙事不因此变化。图形在 img 外部 SVG 中时不能继承外层变量：修改 SVG 内色值或带前缀内联；不可只改页面就宣称全图换肤。

数据图的 `chart-config.json` 有 theme 和显式 method_colors。只改 theme 默认不改变已锁定的 method_colors；如果需要整套重映射，明确修改所有方法映射，并重建全部相关图与图例。CSS 主题不能替代图元颜色和数字核对。

```bash
python3 "$SKILL_DIR/scripts/build_theme_assets.py" "$SKILL_DIR/assets/themes.json" --out "$OUTPUT_DIR"
```

重建目录中放入 tokens.css 才具备完整样式；覆盖已生成文件须显式 `--force`，不要指向用户未授权修改的目录。

## 字体与对比

主题不指定唯一字体。中文正文、节点、数字用实际可用的清晰家族，标题可按语境选展示字体；注意字重、上/下标、数学符号和数字等宽。字体规则详见 [page-recipes.md](page-recipes.md)。

正文目标 4.5:1，大号文字/关键图形按相应标准检查。渐变、透明、纹理和深色章节必须看实际背景；最浅系列色要配深轮廓/符号及直接标签。色盲/黑白场景不能只靠红绿区别。脚本的色值检查不是完整 WCAG 认证。
