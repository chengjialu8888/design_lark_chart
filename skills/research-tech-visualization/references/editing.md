# 局部编辑、重绘与版本

用于已有图表、页面、模板和历史版本的继续修改。

## 先确定当前真源

当前源文件、历史生成快照、用户截图、远端当前保存态是不同对象。默认从最新已确认完整源继续；不能从旧 sidecar 覆盖用户后来修改的图。仅有截图时能重绘可见内容，但隐藏数据、精确坐标、方法定义与原始数值需要材料；像素读数只能标估计值。

| 请求 | 应改 | 应保留 |
| --- | --- | --- |
| 改标题/字体 | 指定文字、必要尺寸联动 | 数据、图型、关系、其他样式 |
| 换主题 | 已授权范围的颜色/字体角色 | 身份映射、数值、轴、拓扑、来源 |
| 改一条边 | 唯一边及必要路由/图例 | 无关节点和关系 |
| 新增实验 | 新数据与受影响比较/表格/刻度 | 旧原值、缺失、方法身份 |
| 加动效 | 已核实路径的装饰/讲解状态 | 完整静态图及无动效阅读 |
| 重绘论文图 | 已核实内容的原生表达 | 关键节点/边集合与来源；简化明确记录 |

## 操作与验收

1. 记录目标对象稳定 ID/业务键、请求字段和锁定项；存在歧义时确认，不自动取第一个同名点。
2. 修改源的任务副本或用户指定文件，保留未知扩展字段，不按新模板从头生成一份“相似图”。
3. 对比前后数据、节点/边集合、来源、顺序、尺寸及非目标样式；必要联动要可解释。
4. 重渲染改动图及真实消费者；公共 tokens/数据更改要检查所有使用者。源哈希变化后旧预览失效。
5. 交付具体改了什么、保留什么和未验证项。导出不等于发布；用户提供 URL 不等于持续同步。

自动刷新需要独立的取数、权限、运行时与验证，不能从 source URL 或一次回读推断存在。跨 ECharts/VChart/SVG/第三方编辑器转换时单独确认标签、关系、交互和可编辑性是否保留。
