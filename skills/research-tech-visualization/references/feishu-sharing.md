# 飞书分享：三条路线

## 先确定读者如何使用

| 用户要什么 | 路线 | 读取 | 不能承诺 |
| --- | --- | --- | --- |
| 在文档内阅读自定义图、指标切换、流程或讲解 | HTMLBox / 妙笔 BOX | [文档嵌入](feishu-htmlbox.md) | 不等于飞书原生数据编辑；本地可运行不证明宿主兼容 |
| 在飞书图表组件里改数据、切换支持的图型 | 飞书原生 AddOns | [原生图表](feishu-native.md) | 不保留任意网页布局、SVG 节点或所有统计表达 |
| 保留独立网页体验，给别人一个访问链接 | 妙搭托管 | [网页分享](miaoda-sharing.md) | 发布完成不等于他人有权限；不默认公网 |

“和飞书结合”“支持三条路线”可能只是分析或 skill 更新，不是远端执行请求。用户只给来源文档时保持只读；已指定具体路线时不再要求用户重复选择。未指定时按用途推荐一条，并只澄清会改变写入目标、受众或编辑方式的缺口。

整份报告可以文档正文 + 多个 HTMLBox；只有确有用途时混合原生图表与自定义模块。多路线共用事实和稳定身份，不为了视觉一致强行让三种 renderer 一样。分享不自动建立源文档同步、实验追踪、后端或定时任务。

## 远端执行前的最小确认

- **动作**：新建文档、插入/替换指定块，还是新建/更新应用？“查看参考”“新增能力”不包含这些动作。
- **目标**：来源和目的地分开；新建副本不等于可以覆盖原文。已有 app/block 有后续人工修改时先确认当前真源，不从旧 sidecar 覆盖。
- **读者**：本人、指定人员/群/部门、租户还是外部？源文档的权限不会自动保护写入另一文档或托管网页的副本。
- **数据范围**：指标、完整配置、内部链接、历史日志与下载文件哪些应分享？先去除凭据及无关敏感材料；原文可读不等于可公开。

用户已明确授权具体目标与范围时直接执行，不逐步重复询问；不把授权扩展到公网、覆盖其他资产或修改组织权限。内网、仅登录可见也不等于已核验的合规分享。

## 工具边界

HTMLBox 和原生路线按需读取实际可用 `consulting-charts` 的入口、对应 reference 与脚本；以本轮定位的目录设置 `CHART_SKILL_DIR`。妙搭按需读取实际可用的 `lark-apps`；正文新建/编辑走可用的 `lark-doc` 或当前飞书文档工具。这些是远端连接依赖，不是本地设计依赖。

按项目、安装列表或用户附件定位 skills，不把某台机器的 Downloads 路径写成运行时常量。未找到时保留本地 HTML/SVG/数据和明确待执行项，请用户提供或安装对应工具，不默默复制旧认证实现。`lark-cli` 通过 PATH 发现；user 身份、scope 和认证处理读取可用 `lark-shared` 或 CLI 内置指引，既有身份可用时不预防性重登、不读取或输出 token。

## 分开记录验证与状态

| 证据 | 可说明什么 |
| --- | --- |
| 数据、原生适配或自包含页面本地检查 | 准备文件正确；尚未写入或发布 |
| HTMLBox/原生 `write_confirmed=true` | 服务端确认写请求；还需内容和视觉核验 |
| HTMLBox `record.html` 或原生业务 record 定点回读一致 | 远端保存了本次内容，不等于客户端已渲染 |
| 真实飞书页面/组件截图及操作 | 所测客户端实际可读可操作，不外推所有客户端 |
| 本轮 release 的 `finished` | 对应版本已部署，不等于权限已放开 |
| 访问范围回读、已授权读者实际打开 | 分别证明配置和所测受众可访问 |

平台操作结果未知时停止自动写入；不跨路线重试。分享记录只存所需 doc/block/app/release 标识、源版本、内容哈希、验证范围与状态，不存密钥、完整认证响应或无关排障日志。
