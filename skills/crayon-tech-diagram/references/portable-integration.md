# 独立包的图像工具边界

核心提示词、参考图和验收方法随包提供；真正生图仍依赖宿主的图像生成／编辑服务，费用与权限以实际服务为准。

- 有 imagegen 或其他可用图像工具时，读取其规则，将内容图与风格图分别传入；参数以真实工具为准，不复制旧提供方参数名。
- 有 doubao-creative-design 时可沿用其 image_edit / 上传流程，先读当前版本的规则。
- 没有图像服务时，交付已准备的提示词和参考资产，明确尚未生成，不能把随包示例当本次生成结果。
- 图像输出是位图插画，不是飞书原生可编辑节点；精确实验数据曲线和线上截图保持原样。
- `scripts/fetch_and_check.py` 使用 Python 标准库下载和识别图片；缩略图需 Pillow 或 macOS sips。脚本读取实际输出格式，不能代替人工审字、箭头和数值检查。
- 此模块独立使用不需要 design-lark-chart、Mck、AgentBuddy 登录或整仓其他模块；飞书写入仅在用户指定时按当前工具执行。
