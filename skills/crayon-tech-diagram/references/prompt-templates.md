本文件收录本 skill 实测通过的中文提示词。写新图时先选最接近的图型模板，替换节点和文字，保留风格段和收尾约束。

## 1. 固定风格段

每条提示词在开头说明画幅和图1/图2的分工，然后原样接这一段：

```text
一张竖版 3:4 的中文技术博客手绘{图型}。图1只提供内容和结构，图2只提供风格，不复制图2的节点、文字和连线。风格完全照图2：纯白背景，深石墨色手绘蜡笔描边与箭头，淡蓝、淡绿、淡橙蜡笔填充的轻微不规则圆角框，填充内可见蜡笔颗粒，自然手写感的大号简体中文，无阴影、无渐变、无装饰、无水印，留白充足，适合手机阅读。
```

没有内容参考图（从文字描述直接画）时，把“图1只提供内容和结构，图2只提供风格”改成“图1只提供风格，不复制图1的节点、文字和连线”，并把后文的“图2”改成“图1”。

## 3. 图型模板

### 3.1 容器 + 进程关系（架构 / 部署关系）

```text
版面从上到下：上方 60% 是一个大的淡蓝色手绘圆角容器，左上角写“{容器名}”；容器内左侧是白底框“{节点A}”，右侧上下两个淡绿色框“{节点B}”和“{节点C}”，{节点A}分别用箭头指向{节点B}和{节点C}；容器底部是一条横跨的淡蓝色框“{说明}”。容器下方是一个淡橙色手绘圆角框“{外部组件}”，框内两行小字“{职责1}”“{职责2}”。两个容器之间有两条分开的平行箭头：从下往上标注“{请求}”；从上往下标注“{响应}”。
```

要点：双向交互一律画两条分开的单向箭头，并分别标注。

### 3.2 上下对比（老方案 vs 新方案）

```text
版面上下两个面板，中间一条浅灰手绘分隔线。上面板标题“{老方案标题}”，下面三个淡橙色框竖向排列并用向下箭头连接：“{步骤1}”→“{步骤2}”→“{步骤3}”。下面板标题“{新方案标题}”，下面三个淡绿色框竖向排列并用向下箭头连接：“{步骤1}”→“{步骤2}”→“{步骤3}”。新方案的三个框比老方案的框略窄小，直观表现数据量变少。底部一条淡蓝色小横条写“{结论}”。
```

要点：橙 = 旧 / 问题，绿 = 新 / 改进；左右分栏在手机上太挤，对比优先上下排。

### 3.3 编号步骤（替代泳道时序图）

```text
不要画成泳道时序图，而是从上到下 {N} 个宽敞的圆角卡片，用向下箭头依次连接，每张卡片左侧有一个手绘圆圈编号：①淡橙色“{步骤}”；②淡蓝色“{步骤}”；……最后一张卡片下方有一条短箭头指向一个小淡橙色气泡“{结果}”。卡片 ②③④ 左侧用一条浅蓝色手绘竖括号标注“{角色A}”，卡片 ⑤⑥ 左侧用一条浅绿色手绘竖括号标注“{角色B}”。
```

要点：时序图在竖版里会挤成一团，改为编号卡片加侧边竖括号标角色，可读性好得多。步骤不超过 7 个。

### 3.4 横向链路 + 进度条（规则 + 数值例子）

```text
上半部分标题“{规则标题}”。第一行是四个小框用箭头横向连接：“{帧1}”→淡绿色“{命中帧}”→“{帧3}”→“{帧4}”，行末箭头指向一个淡绿色圆角标签“{结果}”。第二行同样四个小框……行末箭头指向一个淡橙色圆角标签“{结果}”。下半部分标题“{例子标题}”，三行手绘横向进度条，每行左侧写标签，条内左端都有一小段深绿色蜡笔填充代表{对象}：第一行“{标签}”，条为满长度，其余部分淡蓝色填充，右侧写“{数值}”；第二行……
```

要点：进度条必须逐行写清“深绿段多长、其余部分什么颜色”，否则模型会把整条涂满，比例就错了（见第 5 节）。

### 3.5 双列汇合（两条路径殊途同归）

```text
顶部一个淡蓝色宽框“{共同判断}”。下方分成左右两列，左列标题“{A}”，右列标题“{B}”。左列从上到下三个框用向下箭头连接：“{步骤}”→“{步骤}”→淡绿色“{结果}”。右列同理。两列底部汇合到一个淡橙色宽框“{共同结果}”。最底部一行小字“{一句话结论}”。
```

## 4. 局部修正模板

文字或局部图形出错时，用 image_edit 只传当前出错的图，不重画整图：

```text
保留整图，只改{位置}的{元素}。把它改成{目标状态，写清长度、颜色、位置并参照图中某个正确元素}。其余所有内容，包括{逐项列出标题、其他元素和关键文字}，都保持像素级不变，不新增任何文字。
```

输出尺寸与原图一致（本 skill 默认 1773×2364）。

## 5. 实测问题记录

| 问题 | 出现位置 | 解决办法 |
|---|---|---|
| 进度条整条涂成深绿，比例被画错 | 3.4 第三行“保留汇总” | 用第 4 节模板局部修正，写明“与第一行完全一样：左端约 8% 深绿，其余淡蓝” |
| 卡片底色和描述不一致（写淡蓝画成淡橙） | 3.3 第 ④ 张卡片 | 语义不受影响时可接受；颜色承载语义时用局部修正 |
| 框内长句被模型自行断行 | 3.5 第三行“不进缓冲” | 单框文字控制在 12 个字以内，或主动用两句话写 |
| 下载后的文件实际是 JPEG 但扩展名为 .png | 所有生成图 | 用 `file` 检查格式，按实际格式命名后再插入文档 |
